p.drive_missing.title = Drive {drive} not found
p.drive_missing.what = "{game}" is on drive {drive}. This drive isn't available right now.
p.drive_missing.why = Usually an external hard drive or USB stick isn't plugged in, or the drive got a different letter.
p.drive_missing.steps = Plug in the external hard drive or USB stick the game is on.\nWait a few seconds until Windows detects the drive (it then shows up in File Explorer under "This PC").\nClick "Play" in the launcher again.\nDoes the drive have a different letter now (e.g. E: instead of D:)? Then click "Edit game" and choose the EXE file again.

p.exe_missing.title = Game file not found
p.exe_missing.what = The launcher wanted to start "{game}", but the file no longer exists at this location.
p.exe_missing.why = The game was probably moved, renamed, deleted or reinstalled. Sometimes an antivirus program removes the file.
p.exe_missing.steps = Click "Edit game" below.\nClick "Browse…" next to "Program".\nFind the folder where the game is now and choose the start file (usually named like the game and ending with .exe).\nClick "Save" and then "Play" again.\nCan't find the file at all? Reinstall the game and repeat the steps.\nDid your antivirus delete the file? Check your antivirus quarantine and restore it (only if you trust the game).

p.workdir_missing.title = Working folder not found
p.workdir_missing.what = A working folder is set for "{game}" that doesn't exist.
p.workdir_missing.why = The folder was moved or deleted.
p.workdir_missing.steps = Click "Edit game".\nDelete the text in the "Working folder" field (leaving it empty is totally fine – the launcher then uses the EXE's folder).\nClick "Save" and start the game again.

p.admin_required.title = The game needs administrator rights
p.admin_required.what = "{game}" wants to be started with administrator rights.
p.admin_required.why = Some games (or their anti-cheat programs) need more rights to work. That's normal.
p.admin_required.steps = Click "Run as administrator" below.\nWindows then asks "Do you want to allow…" – click "Yes".\nSo you don't have to do this every time: click "Edit game" and turn on "Always run as administrator".

p.access_denied.title = Access denied
p.access_denied.what = Windows didn't allow "{game}" to start.
p.access_denied.why = Either rights for the folder are missing, the file is blocked by Windows (downloaded file), or an antivirus program blocks it.
p.access_denied.steps = First try "Run as administrator" (below). Windows asks – click "Yes".\nIf that doesn't work: open the game folder (button below), right-click the EXE file → "Properties".\nAt the very bottom of the "General" tab there may be "Unblock". Tick it and click "OK".\nStill not working? Open your antivirus program and check whether it blocked the file. If you trust the game, add it as an exception there.\nIs the game in "C:\Program Files"? Then it often helps to install the game into its own folder like "C:\Games".

p.not_an_app.title = That's not a game file
p.not_an_app.what = Windows can't start the file chosen for "{game}" as a program.
p.not_an_app.why = Probably the wrong file was chosen, the file is broken (e.g. incomplete download), or the game is made for a different system.
p.not_an_app.steps = Click "Edit game".\nClick "Browse…" and choose the right start file. It ends with ".exe" and is usually named like the game – not "unins000.exe", "setup.exe" or "UnityCrashHandler.exe".\nSave and start again.\nIs the file broken? Then download or reinstall the game.

p.virus.title = Blocked by antivirus
p.virus.what = Your antivirus blocked "{game}" because it thinks the file is dangerous.
p.virus.why = It can be a real virus – or a false alarm, which happens a lot with mods and small indie games.
p.virus.steps = Important: only continue if you're sure the file comes from a trustworthy source!\nOpen "Windows Security" (button below).\nClick "Virus & threat protection" → "Protection history".\nFind the entry for the game, click it and choose "Allow" or "Allow on device".\nUsing another antivirus (e.g. Avast, Norton, Kaspersky)? Open it and add the game under "Exceptions".\nThen start the game here again.

p.blocked.title = Blocked by Windows
p.blocked.what = Windows blocked "{game}" with a security rule (e.g. "Smart App Control" or the policies of your work/school PC).
p.blocked.why = Windows only lets programs start that it trusts. Unknown games are then blocked.
p.blocked.steps = Is this a work or school PC? Then please ask your IT admin – you usually can't change this yourself.\nOn your own PC: open "Windows Security" → "App & browser control".\nCheck whether "Smart App Control" is turned on. If you trust the game, you can turn it off there (careful: it can't easily be turned back on).\nThen start the game here again.

p.in_use.title = The file is in use
p.in_use.what = "{game}" is currently opened by another program and can't be started.
p.in_use.why = Maybe the game is already running in the background, being updated, or an antivirus is scanning it.
p.in_use.steps = Wait a moment (about 30 seconds) and try again.\nPress Ctrl + Shift + Esc to open Task Manager. Find the game, click it and then "End task".\nIf that doesn't help: restart the PC.

p.no_assoc.title = No program for this file type
p.no_assoc.what = Windows doesn't know which program should open the file of "{game}".
p.no_assoc.why = The chosen file isn't an EXE, but e.g. an image, an archive (.zip/.rar) or an unknown file.
p.no_assoc.steps = Is it a .zip or .rar file? Then you have to extract it first (right-click → "Extract all…").\nThen click "Edit game" here and choose the .exe file in the extracted folder.

p.dll_missing.title = An important Windows file (DLL) is missing
p.dll_missing.what = "{game}" closed right away because a required extra file is missing.
p.dll_missing.why = Almost all games need free Microsoft packages ("Visual C++" and "DirectX"). They're not (fully) installed on your PC.
p.dll_missing.steps = Click "Download Visual C++ (64-bit)" below. Open the downloaded file, tick "I agree" and click "Install".\nDo the same with "Download Visual C++ (32-bit)" – yes, both! Many games need both versions.\nClick "Download DirectX", download and install it.\nRestart the PC.\nStart the game here again.\nStill broken? Look in the game folder for a subfolder like "_CommonRedist", "Redist" or "DirectX" and install everything in it.

p.bad_image.title = Error 0xc000007b – system files don't match
p.bad_image.what = "{game}" couldn't start properly (the famous error 0xc000007b).
p.bad_image.why = The game is missing matching Microsoft packages, or 32-bit and 64-bit files got mixed up.
p.bad_image.steps = Install "Visual C++ (64-bit)" AND "Visual C++ (32-bit)" with the buttons below. If asked, choose "Repair".\nInstall "DirectX" with the button below.\nRestart the PC.\nStart the game again. If it still doesn't work: reinstall the game.

p.dll_init.title = The game couldn't get ready
p.dll_init.what = "{game}" got stuck while starting and quit (error 0xc0000142).
p.dll_init.why = Often it's caused by programs in the background (overlays, recording tools, antivirus) or an old graphics driver.
p.dll_init.steps = Restart the PC – this very often fixes the error.\nClose overlays and recording programs (e.g. Discord overlay, MSI Afterburner, OBS) and try again.\nUpdate your graphics driver (buttons below: NVIDIA, AMD or Intel – depending on your graphics card).\nInstall the Visual C++ packages (64- and 32-bit).

p.crash.what = "{game}" crashed directly after starting.
p.crash.why = Common reasons: old graphics driver, broken game files, missing rights or a background program that interferes (e.g. overlay or antivirus).
p.crash.steps = Restart the PC and try again.\nUpdate your graphics driver (buttons below).\nTry "Run as administrator".\nClose overlays and background tools (Discord overlay, MSI Afterburner, RivaTuner, OBS).\nNothing helps: reinstall the game. With mods: remove the mods and test without them.

p.quit_early.title = The game closed right away
p.quit_early.what = "{game}" was started, but closed again after a few seconds with an error code.
